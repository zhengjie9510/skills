# Skills

简体中文 | [English](./README.en.md)

这是我在日常使用 AI 工具的过程中整理和总结的一些技能，也收录了一部分来自社区的优秀实践。

仓库中的自有技能会根据实际使用持续调整；第三方技能会保留原作者、来源和许可证信息。下方还整理了一些值得关注的技能库，方便后续查阅和筛选。

## 安装

在 Claude Code 中添加本仓库：

```text
/plugin marketplace add zhengjie9510/skills
```

然后按需安装技能包：

```text
/plugin install jason-agent-skills@jason-agent-skills
```

## 已收录技能

| 技能名称 | 说明 |
| --- | --- |
| `zotero` | 搜索、阅读、整理和修改 Zotero 文献库 |
| [`karpathy-guidelines`](https://github.com/multica-ai/andrej-karpathy-skills) | 在编写和修改代码时减少过度设计、无关改动和未经确认的假设 |
